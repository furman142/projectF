# ג׳וקר (Joker)

משחק קלפים מהיר לנייד: אוספים רביעייה, ולא נתקעים עם הג׳וקר. PWA בעברית (RTL), שחקן אחד מול 2–5 בוטים.

## הרצה

```bash
npm install
npm run dev        # פיתוח, כולל גישה מהרשת המקומית
npm test           # בדיקות ללוגיקת המשחק
npm run build      # בנייה ל-dist/
npm run preview    # הגשת הגרסה הבנויה (כולל service worker)
```

`npm run dev` ו-`npm run preview` מדפיסים כתובת `Network` (למשל `http://192.168.1.20:5173`). פתחו אותה בטלפון שמחובר לאותו Wi-Fi.

התקנה למסך הבית ומשחק אופליין דורשים HTTPS (דפדפנים לא מפעילים service worker מעל `http://` ברשת מקומית). לשם כך מעלים את התיקייה `dist/` לכל אחסון סטטי עם HTTPS (GitHub Pages, Netlify, Cloudflare Pages). הבנייה משתמשת בנתיבים יחסיים, כך שהיא עובדת גם מתת-תיקייה.

## חוקים

- חפיסה: רביעייה אחת לכל שחקן (4 שחקנים: A, K, Q, J) ועוד ג׳וקר אחד.
- כל שחקן מקבל 4 קלפים; שחקן אקראי מקבל את הג׳וקר כקלף חמישי.
- בכל סיבוב כולם מעבירים בו-זמנית קלף אחד לשחקן שמשמאלם.
- מי שקיבל את הג׳וקר חייב להחזיק אותו סיבוב אחד לפני שיעביר אותו.
- בקשת קלף (אפשר לכבות בהגדרות): פעם אחת בכל חלוקה כל שחקן יכול לבקש דרגה מהשחקן שמעביר אליו. אם יש לו קלף כזה, הוא חייב להעביר אותו באותה העברה, גם במקום הג׳וקר.
- מי שמחזיק ארבעה קלפים זהים (ואין לו ג׳וקר ביד) מכריז "רביעייה!".
- מי שמחזיק את הג׳וקר ברגע ההכרזה מפסיד ומקבל אות. מי שהשלים J-O-K-E-R יוצא; האחרון שנשאר מנצח.

## מבנה

```
src/game/   לוגיקה טהורה, בלי DOM (מוכנה לשימוש גם בשרת למשחק מקוון)
  deck.ts     חפיסה, ערבוב, חלוקה
  rules.ts    העברה, נעילת הג׳וקר, זיהוי רביעייה, קביעת מפסיד
  score.ts    אותיות, הדחה, מנצח
  bot.ts      בוטים: קל / קשה
  engine.ts   reduce(state, action) ומחולל אקראיות עם seed
src/ui/     תצוגה: שולחן, קלפים, אנימציות, מסכים, צלילים
tests/      בדיקות Vitest ללוגיקה
```
